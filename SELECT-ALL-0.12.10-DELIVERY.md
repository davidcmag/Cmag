# Email Grabber 3 — Select all 0.12.10

Source: EmailGrabber3-Mac-Select-All-0.12.10.zip
SHA256: a0d8e0480d238138093cb730a541002e21671fb38e6d4342d7e5b314ab32d7f2

Adds clearly labeled Select all (count) and Deselect all controls with the selected
count beside them. Select all selects every row in the current list, including
offscreen rows, respecting address type, search and status filters. Without filters,
it selects the whole list. Selection remains a snapshot: later crawl discoveries
are not automatically selected. Selection does not remove or modify saved data.
Existing removal, Undo, verification and CSV behavior are unchanged.

252 portable regression tests passed. SwiftUI syntax, Xcode project references,
shell syntax, archive integrity and internal checksums passed. Native macOS build
and GUI behavior remain unverified on Linux. No public mailbox probes or paid
verification were run. Quit the older app before opening this version.
